# FORM — Athletic Club 🏋️

A modern, responsive gym website template designed with a premium fitness aesthetic, bold typography, smooth animations, and an attractive user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive design for mobile and desktop
- Smooth animations and scrolling effects
- Training programs and coach sections
- Membership pricing plans
- WhatsApp enquiry form
- Modern and premium UI design

## How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Customize the content, images, and contact details as needed.
